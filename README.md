# HTML5 Final Project — Exploring Vietnam

A semantic, accessible HTML5 page showcasing top travel destinations in Vietnam, built for the **Introduction to HTML5** final project (Web Design for Everybody Specialization).

## Repository Structure

```text
repository/
├── README.md
├── index.html
└── images/
    ├── ha-long-bay.jpg
    ├── hoi-an.jpg
    └── sapa.jpg
```

## Rubric Coverage

- Valid `<!DOCTYPE html>`, `<html lang="en">`, `<head>` with descriptive `<title>`, and `<body>`.
- Semantic HTML5 tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<figure>`, `<figcaption>`, and `<footer>`.
- Properly formatted `<ul>` lists with 3 items each and working internal section links (`#places`, `#gallery`, `#more`).
- Three local working JPEG images in `images/` with descriptive `alt` text.
- Working external link to the [Official Vietnam Tourism Website](https://vietnam.travel/).
- Validated with zero W3C Markup Validation errors and zero WAVE accessibility errors.
